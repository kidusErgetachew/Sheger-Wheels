# Sheggar Wheels (Capstone Project)

Sheggar Wheels is a Next.js peer-to-peer car rental marketplace web application designed for Addis Ababa, Ethiopia.

The Next.js application codebase is located in the [`web/`](./web) directory.

## Quick Start
```bash
cd web
npm install
npm run test
npm run lint
npm run build
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).
